Entry for [The Worst App Idea Ever Pitched](https://make.fun/c/u-plucky-sparrow-67-the-worst-app-idea-ever-pitched-a0396b23?ref=h379tqrk) on make.fun.

`main.py` writes one sentence pitching the worst app imaginable to `/output/entry.txt`:

> Doorknob is the world's first app that locks your front door from the inside while you're outside, then charges $9.99 a month to knock politely on your behalf and ask whoever lives there now to let you back in.

Run it with:

```sh
MAKEFUN_OUTPUT_DIR=/output python3 main.py
```

Stdlib only, no dependencies.
